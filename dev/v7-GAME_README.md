# 百妖夜契 · 雾中归藏版

## 启动与操作

完整目录解压后打开 `index.html` 并保留 `assets/`，或直接打开完整单文件 `baiyao-standalone.html`。游戏离线运行，不安装依赖、不登录、不调用大模型或服务器。进行中的一局不保存；已解锁角色单独保存在浏览器。换文件位置、浏览器或设备前，可在“解锁凭证”复制凭证，再到新位置载入。

先选职业与起手构筑，再进入当前地域。攻击／状态牌先点牌再点敌人；同牌再点一次或按 Esc 取消，不扣费。无目标牌直接使用。每回合基础 3 灵力、抽 5 张，手牌上限 10；结束回合后执行提前展示的准确固定敌人意图。牌堆、牌组、战斗日志、装备和行旅手记可随时查看。装备只可在战斗外更换。

## 绘制场景与随机路线

当前版本移除三维模型，人物由原画、三档战损与 CSS 战斗演出呈现。地图节点和真实连线铺在地域画上，战斗也使用当前地域背景。宽屏显示本境全部路径，窄屏可横向查看地图，也可以使用下方当前路线卡。图片缺失会显示 SVG 后备，不阻塞游玩。

开局从 20 套不同布局的完整路线模板随机选择一套，每套 44—48 个节点，分成十二段、三境：雾锁山门（1—4 段）、断桥诸营（5—8 段）、逆仪腹地（9—12 段）。每段只选择一个相连节点，同层其他节点随之错过；走完当前境再开放下一境。四十多个节点是分支总量，并非一局要顺序打四十多场。

普通位置随机安排战斗、精英、休息、商店与奇遇；固定开场、终点和少量叙事枢纽保证完整流程。精英和狐妖不保证每局都出现。普通奇遇优先使用未见过的独立事件；人物后续事件必须已有相识前情，隐藏线索也不放进早期随机池。20 套模板均有实际不同布局，不是同一张图换二十个名字。

## 地域影响

| 地域 | 效果 |
| --- | --- |
| 雾锁山门：入骨瘴 | 每场入场时获得 1 毒；首回合开始失去 1 生命后毒消散。 |
| 断桥诸营：逆灵风 | 每场首个玩家回合灵力 −1，其后恢复正常。 |
| 逆仪腹地：离魂隙 | 从第 3 个玩家回合起，每回合开始直接失去 1 生命，无视护盾。 |

地域效果在抵达、地图与战斗页写明。生命归零会按普通规则触发免死或失败，不会继续完成已死亡角色的剩余效果。

## 灵识与剑器

初始灵识 1 级、历练 0。普通战胜利加 1 历练，精英加 2，Boss 加 3；等级为 `1＋向下取整(历练/2)`，最高 6 级。等级和剑器仅在本局保留，重开清空。

| 剑器 | 灵识要求 | 实际作用 |
| --- | --- | --- |
| 行旅佩刃 | 1 | 初始普通佩刃，无额外效果。 |
| 听雪 | 2 | 每回合首张攻击牌第一段伤害 +2。 |
| 回灯 | 2 | 每回合首张攻击牌第一段 +1；每场首回合获得 3 护盾。 |
| 照夜 | 4 | 每回合首张攻击牌第一段 +4；允许提前装备，但会反噬。 |

照夜在灵识不足 4 级时，按玩家回合固定循环干扰：灵力 −1 → 直接失去 3 生命 → 敌人获得 6 护盾，然后重复。灵力、伤害和护盾都真实结算，当前干扰会显示并记日志；达到要求后不再干扰。剑器可以从事件或商店获得；新剑不会偷偷自动装备，能在行囊中收剑换用普通佩刃。普通听雪／回灯等级不够时不能装备。

## 角色与事件

夜铃使用 36 张刺客牌，保留猎印、连段与血契三种开局；沈霜白使用 16 张冰剑牌，霜寒上限 4，减少敌人下一行动每段攻击，行动后清空；剑意上限 8，跨回合保留，指定剑诀可消费爆发。

共 34 种剧情事件，另有狐妖、商店和休息。事件不再提供人物简介或预告立场的身份标签，只写当场见闻与对话。第二段可与不同人物相识，在后方地域再次相逢；先前的选择会影响实际治疗、援护、交易、追踪与交战。所有即时数值代价写在选项上，已处理事件不能重领。行旅手记记录已知经过，不替玩家提前判定人心。

有主角出镜的 21 类场景为剑修与解锁角色分别制作独立版本，共 42 张职业画面；猫妖保留对应原画。只描绘相同 NPC 的画面可以共用，并不把 NPC 当成当前主角。

## 额外相逢与解锁旅程

三处线索分别需要相应的选择。集齐后打赢当前终战，才会出现可选的进一步探索；可以带着已有战果离开，也可以接受额外挑战，失败仍会结束本局。击败井声之后的来客，解锁第三位角色。尚未相遇前，首页只显示未解锁的空位。

解锁角色拥有 12 张专属技能，魂息最多 6、跨回合保留。她会遇到自己的旧影、旧部与心中的回声；相应战斗胜利会收回本源，上限 3，使每张攻击牌的第一段额外增加等量伤害。三境都有专属前情与实际战斗，终战也有不同数值和行动，不只是更换立绘。重新开始清空本局本源、历练、装备和剧情标记，但保留角色解锁。

## 原有战斗与奖励

护盾先挡普通攻击，毒与自损无视护盾，连击逐段结算。标记上限 5，不自动增强所有牌；扑杀等指定效果才消费标记。正在结算的牌不能先进入弃牌堆抽回；消耗只对本场生效，下场恢复。商店删掉的是本局独立实例，下场仍然删除。

普通战奖励 20 金币与三选一卡；精英 35 金币、稀有卡保底与两件珍藏中选一件。首次精英保底有秘宝候选。本局一次免费换牌，不重复发钱或重抽珍藏。休息回复 18 生命；狐契付 8 最大生命换一次免死。商店商品、事件选项和奖励进入时固定。

## 编辑与构建

主要规则在 `dev/engine.js`，新增职业／装备／地域数据在 `dev/expansion.js`；UI 在 `dev/ui.js`、`dev/shell.html`；声音在 `dev/audio.js`；SVG 后备在 `dev/art.js`。运行包不再加载旧三维或网格立绘模块。

```sh
node dev/build.cjs --strict
node dev/build.cjs --strict --inline --output baiyao-standalone.html
node dev/build.cjs --slim --output /tmp/baiyao-slim.html
```

只有编辑源码后构建才需要 Node；游玩成品不需要。实际执行范围与尚未验证内容见 `TESTING.md`。
