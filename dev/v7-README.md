# 百妖夜契 · 雾中归藏版

玄烬教实验反噬，寒渊被黑雾封闭。选择影契刺客夜铃或霜华剑修沈霜白，沿雾锁山门、断桥诸营、逆仪腹地逐境深入，遇见各有去处的行者。事件只写当场发生的事与对话，人物的打算由你在途中判断。

本版使用绘制背景、二维路线和角色原画，移除了三维模型。开局从至少 20 套真实线路模板中抽取一套，每套不少于 40 个节点；节点内的战斗与奇遇再随机安排。选择一次只走当前一段，同层支路互斥，后续区域抵达时才开放。需要前情的故事与隐藏线索单独调度。

地域各有瘴气、逆风或离魂侵蚀，界面会写明实际效果。获得剑器后可在战斗外更换；灵识未达要求时，神剑照夜仍可出鞘，但会按明示的回合顺序干扰战局。灵识随战斗经验成长，并非装饰等级。

井声背后还有一场可选相逢。满足多项线索、完成当前挑战后，才有机会前往；胜利会解锁第三位角色。她拥有专属牌组和重走故地的旅程，散落的力量、旧人和心中的回声都将成为真实遭遇。已解锁角色独立记在浏览器里，可导出凭证；进行中的一局仍不保存。

## 下载与启动

- [完整游戏 ZIP](https://raw.githubusercontent.com/YONGLINGZ/CC/main/recovery/baiyao-rebuilt.zip)：全部解压，打开 `index.html`，保留 `assets/`。
- [完整单文件 HTML](https://raw.githubusercontent.com/YONGLINGZ/CC/main/baiyao-standalone.html)：保存为 `.html`，用桌面浏览器打开。

完全离线，无需安装、服务器、账号或大模型 API。攻击牌先点牌再点敌人；同牌再点一次或按 Esc 取消，无目标牌直接使用。顶部可以看牌组、行旅手记、装备和解锁凭证。

主角出镜的事件按所选职业显示对应画面；只描绘相同 NPC 或景物的画面可以共用。攻击特效、独立技能音效、三档战损原画和精英秘宝均保留。玩法见 [GAME_README.md](GAME_README.md)，实际验证范围见 [TESTING.md](TESTING.md)。
