# 当前人物与场景表现

雾中归藏版按用户的新要求移除三维人物、三维路线以及运行时 WebGL 模块，改用绘制的地域背景、二维路线连线和静态角色原画。旧三维源码与测试已从当前版本删除，历史实现可在此前 Git 提交查看。

三位可用角色均使用独立原画和 50%／25% 生命阈值的三档战损图，保留 CSS 攻击位移、残影、技能效果、受击和数字反馈。旧加权网格二维立绘模块不再进入运行包；当前版本也没有声称具备正式 Live2D Cubism 模型。

无 `.cmo3`、`.moc3` 或精细骨骼模型文件。原图缺失时显示内联 SVG 后备，路线与战斗不会被图片加载阻塞。不同角色出镜的事件拥有对应画面，NPC 独立画像可以共用。

此前的动态与模型调查记录保存在 `dev/v6-LIVE2D_STATUS.md`，仅为历史，不能代表本版仍保留这些模型。
