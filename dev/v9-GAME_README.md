# 百妖夜契 · 蚀心长夜版

## 启动与操作

解压完整目录后打开 `index.html` 并保留 `assets/`，或打开完整单文件 `baiyao-standalone.html`。成品离线运行，无需安装依赖、登录或连接服务器。进行中的一局不保存；已解锁角色单独保存在浏览器，更换位置、浏览器或设备前可复制“解锁凭证”。

先选职业与起手构筑。攻击／状态牌先点牌再点敌人，同牌再点一次或按 Esc 取消，不扣费；无目标牌直接使用。每回合基础 3 灵力、抽 5 张，手牌上限 10。敌人的下次固定行动与准确数值提前展示。牌堆、牌组、日志、装备和手记均可查看，装备只在战斗外更换。

## 三境三十段

| 地域 | 全局段数 | 本境终点 |
| --- | --- | --- |
| 雾锁山门 | 1—10 | 第十段 Boss |
| 断桥诸营 | 11—20 | 第十段 Boss |
| 逆仪腹地 | 21—30 | 第十段 Boss |

每境独立从 20 套真实布局中抽取模板，每套十段、42—46 个地标；全局共三十段、126—138 个分支地标。每段只选择一个相连节点，同段其他分支随之错过。走完当前境才开放下一境，分支总量不等于必须完成的战斗数量。

路线从地图底部的第一段向上延伸，到达顶部第十段 Boss。节点与贝塞尔连线铺在同一幅地域画上，行宽和位置错落。各职业使用同一套装饰性 SVG 节点图标，配合战斗、精英、休息、商店、奇遇等短标签辨认去处。地图可上下滚动，窄屏还可横向查看；返回地图时在容器内定位当前段，也可使用路线卡。仅亮起且相连的节点能进入，固定终点与叙事枢纽保证前置逻辑。

## 查看状态与手记

界面以小 SVG 符号呈现已知状态，点击符号查看具体说明。战斗中的剑意、魂息、余势等也通过符号查看当前状态与数值，珍藏符号可打开珍藏面板。生命、金币、灵力、护盾和敌人意图仍显示实际数值。牌面、牌组与预览按当前实际效果写出数值。

旅途中有些影响会跨节点、跨战斗延续。普通治疗恢复生命，压制与根治各有作用，须结合当时已知的状态说明判断。尚未察觉的异状会随经过揭露；人物、招式与事件画面也会反映旅途中的变化。

手记用自然文字记录已发生的见闻与选择。相识、重遇和余波沿此前经历展开，途中获得的物品与功法也由实际剧情交代。

## 地域影响、灵识与剑器

| 地域影响 | 实际效果 |
| --- | --- |
| 山门：迷路雾 | 每场首个玩家回合少抽 1 张牌，之后恢复正常。 |
| 断桥：逆灵风 | 每场首个玩家回合灵力 −1，之后恢复正常。 |
| 腹地：离魂隙 | 每个玩家回合首张攻击牌第一段基础伤害 −1，最低为 0；额外剑器增伤照常。 |

初始灵识 1 级、历练 0。普通战胜利加 1 历练，精英加 2，Boss 加 3；等级为 `1＋向下取整(历练/2)`，最高 6 级。

| 剑器 | 灵识要求 | 作用 |
| --- | --- | --- |
| 行旅佩刃 | 1 | 初始佩刃，无额外效果。 |
| 听雪 | 2 | 每回合首张攻击第一段伤害 +2。 |
| 回灯 | 2 | 每回合首张攻击第一段 +1；每场首回合护盾 +3。 |
| 照夜 | 4 | 每回合首张攻击第一段 +4，可提前装备但会反噬。 |

照夜在灵识不足 4 时，按玩家回合固定循环干扰：灵力 −1 → 直接失去 3 生命 → 敌人获得 6 护盾。达到要求后不再反噬。听雪／回灯等级不足不能装备。新剑收入剑匣后由玩家选择装备，重开清空等级、历练和装备。

## 三职业与故事

夜铃有 36 张刺客牌，保留猎印、连段、血契三种起手。沈霜白有 16 张冰剑牌及六张剧情功法牌：霜寒上限 4，减少敌人下次行动每段攻击，行动后清空；剑意上限 8，跨回合保留。解锁后的绯夜有 12 张专属牌，魂息上限 6，按具体牌面蓄积或消耗。合计 70 张技能。

共 40 种剧情事件，另有狐妖、商店、休息三类固定遭遇。事件呈现已见事实与对话，选择会影响实际援护、交易、追踪及交战；已处理内容不能重复领取。

探索三境可能发现额外道路与挑战，胜负会影响本局结果及角色解锁。第三位角色有专属事件、旧影与旧部的实际战斗，以及不同的终战。相应胜利可收回本源，上限 3，每层强化每张攻击牌第一段。重新开始清空本局养成与故事，保留角色解锁。

## 战斗与奖励

护盾先挡普通攻击，毒与自损无视护盾，连击逐段结算。战斗中的普通层数毒会在持有者回合开始造成层数伤害并减 1，与旅途持续异状分别处理。标记上限 5，只有写明互动的招式消费标记。正在结算的牌不能提前进入弃牌堆抽回；消耗仅对本场生效，下场恢复。

普通战奖励 20 金币与三选一卡；精英奖励 35 金币、稀有牌保底与两件珍藏中选一件，首次精英保底含秘宝候选。本局有一次免费换牌，不重复发钱或重抽珍藏。狐契付 8 最大生命换一次免死。商店删牌 40 金币，删除本局指定实例，至少保留五张；商品、事件选项和奖励进入时固定。

## 画面与构建

运行资源共 233 张 WebP，沿用三职业事件画面、人物三态与现有事件变体。地图和状态符号是内联 SVG，无需新增 WebP。人物采用静态原画、生命三态和 CSS 位移／残影／技能特效，没有正式 Live2D Cubism 模型或三维场景。缺图时显示内联 SVG 后备，不阻塞规则流程。

规则在 `dev/engine.js`，职业、功法、装备及地域数据在 `dev/expansion.js`；UI 在 `dev/ui.js`、`dev/shell.html`，声音在 `dev/audio.js`，SVG 图标与后备在 `dev/art.js`。

```sh
node dev/build.cjs --strict
node dev/build.cjs --strict --inline --output baiyao-standalone.html
node dev/build.cjs --slim --output /tmp/baiyao-slim.html
```

仅编辑源码后构建需要 Node。验证范围见 `TESTING.md`，恢复说明见 `PERSISTENCE.md`。没有固定通关时长承诺，自动模拟胜率不能替代人工平衡评价。
