# 蚀心长夜版 · 人物与场景表现

当前运行包使用绘制地域背景、二维路线及静态角色原画，没有三维人物、三维路线或运行时 WebGL 场景，也没有正式 Live2D Cubism 模型。

三位职业与入魔后的沈霜白均有正常、战损、濒危三档原画，按高于 50%、不高于 50%、不高于 25% 的生命阈值切换。攻击、受击、治疗、魔念和入魔反馈由 CSS 位移、残影、光效与数值提示表现，不能据此称为可绑定骨骼的 Live2D。

运行资源共 233 张 WebP，含 21 张入魔剑修事件变体。入魔保留沈霜白的角色姓名与本局身份，更换神态、人物图与对应事件画面。共用 NPC 画像不代表切换玩家角色。

没有 `.cmo3`、`.moc3`、Cubism SDK 或精细骨骼模型文件。图片缺失时使用内联 SVG 后备；地图和战斗规则仍可运行。此前实现记录见 `dev/v7-LIVE2D_STATUS.md` 与 `dev/v6-LIVE2D_STATUS.md`，仅对应历史版本。
