# 衣影逐帧 · 五角色图集

基于本仓库 assets/puppet/*-normal.webp 的角色外观，使用图像生成工具制作；不是真人手绘声明，不是 Live2D。五个 .webp 图集各为 1024×1536 RGBA、4列×6行，每格256×256。

行0待机，行1普通攻击，行2强攻，行3施术，行4防御，行5受击。各行四张真实绘制姿态；不是对一张全身图做旋转或缩放来伪造帧。*-fullbody.webp 是第一格全身设计的256像素导出，不是额外的高清大图。

人物以向右的四分之三视角作战。统一格子锚点底部中央；图内脚底仍有小幅生成误差。五种基本服装固定，不随装备或战损换整套帧；原身份图的战损变化仍保留。魔修牌使用沈霜白的基础动作配血／魂特效，没有另做堕落服装图集。

每张牌的共享动作与特效见 dev/actor-coverage.js 和 docs/review-v7/CARD_COVERAGE.csv。攻击起手播放0/1帧，实际命中事件播放2/3帧；多段攻击重复命中段。受击仅在对应角色实际受到伤害时播放，不把机体受伤当作本体受伤。

生成原始 PNG 随素材交付包提供；dev/prepare-actors.py 可据其重新编码。背景有透明通道，边缘少量半透明像素保留发丝；不能保证完全无晕边。敌人与三具机傀本轮未重绘。
