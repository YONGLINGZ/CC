# 百妖夜契 · 蚀心长夜版

玄烬教实验反噬，寒渊被黑雾封闭。选择影契刺客夜铃、霜华剑修沈霜白，或在旅途中解锁第三位角色，沿三境深入。事件呈现当场见闻与对话，人物的打算留待途中判断。

本版每境十段，从地图底部第一段向上行至顶部第十段 Boss；三境共三十段。每境独立从 20 套线路模板抽取布局，包含 42—46 处互斥分支地标，全程合计 126—138 处。每段只走一个相连地标。各职业共用装饰性 SVG 路线图标与简短标签，连线随地形错落展开；地图会在容器内定位当前段，后方地域抵达后开放。

战斗与旅途中的已知状态以小图标呈现，点击符号可查看说明。手记用自然文字记下实际经历，陌生功法与人物变化随故事逐渐显露。卡牌与预览中的伤害、护盾等数值按当前实际效果显示。

三职业共 70 张技能、40 种剧情事件，另有狐妖、商店与休息。装备、灵识成长、地域影响、可选隐藏挑战及解锁角色的专属道路保留。进行中的一局不保存，角色解锁单独存于浏览器，也可复制凭证迁移。

## 下载与启动

- [完整游戏 ZIP](https://raw.githubusercontent.com/YONGLINGZ/CC/main/recovery/baiyao-rebuilt.zip)：全部解压，打开 `index.html`，保留 `assets/`。
- [完整单文件 HTML](https://raw.githubusercontent.com/YONGLINGZ/CC/main/baiyao-standalone.html)：保存为 `.html`，用桌面浏览器打开。

完全离线，无需安装、账号或大模型 API。攻击牌先点牌再点敌人，同牌再点一次或按 Esc 取消；无目标牌直接使用。顶部可查看牌组、手记、装备和解锁凭证。

运行资源共 233 张 WebP，人物与事件变体沿用现有原画；地图与状态图标直接使用内联 SVG，无需新增图片。人物表现采用静态原画、生命三态和 CSS 特效，没有正式 Live2D Cubism 模型或三维场景。玩法见 [GAME_README.md](GAME_README.md)，验证记录见 [TESTING.md](TESTING.md)，恢复说明见 [PERSISTENCE.md](PERSISTENCE.md)。

v9 实机画面：[上行地图](docs/previews/map-v9.webp) · [战斗状态](docs/previews/battle-v9.webp) · [窄屏状态详情](docs/previews/status-v9.webp)。战斗图采用边界测试 fixture，灵力及敌方生命等数值经过安排，仅用于展示状态，不代表自然开局；地图图展示真实模板布局，状态图展示点击符号后的详情。
