# 百妖夜契 · 寒渊七境

本轮更新 **器物与来意 · P1**：落实用户方案的首批六种关联小怪、两处可交涉洞府、四件立场凭证与两件专属援助。持有效支持凭证会被相应NPC识别并进入正常精英战；反对凭证可交谈，调查证物只开启问询。和平、救助、主动进攻和离去分别结算，一次机会不能双领。新绘20张运行画作（六待机＋六战斗＋六物品＋两背景），PNG母图单独保留。

此前更新 **衣影与血誓**（2026-10-24，北京时间）：补齐九位镇境者与五个特殊遭遇的背景和连续旧事，共十四套三段任务链、42个四选项阶段；保留机仆两件信物齐全时自动唤醒、避战进境的结果。新增五套真实衣装、六张换血／夺生禁术及三个连续获取事件。战斗与人物志均已移除下一招的预测和招式序列，动作发生后仍显示实际伤害与日志。

夜铃与沈霜白各有五张换装图，沈霜白异变后另有五张对应图；五件衣装也各有物品原画。连同六张技能图、三个事件场景和四位剧情 Boss 重绘，该次新增33张独立生成画作。见[换装与禁术规则](docs/OUTFITS_AND_BLOOD.md)、[十四套 Boss 旧事](docs/BOSS_QUESTS.md)。

玄烬教的引灵实验反噬，寒渊被黑雾封闭。选择影契刺客夜铃、霜华剑修沈霜白，或在旅途中解锁第三位角色，沿七境深入。事件只交代当场见闻与对话，人物的打算留待途中判断。此前十套三阶段人间故事、洞府探索、人物支线与途中变故继续保留，每局只读取真正经历过的选择。

每境十段，从地图底部向上抵达顶部 Boss；全程七十段。每境独立从20套线路模板抽取布局，包含42—46处互斥分支地标。小型五边形图标与连线表示真实通路，每段只能走一个相连节点，下一境抵达后开放。

镇境阵容共有九位：前期五位依境按不同权重抽取三位且不重复，第四至第六境分别面对三位中期镇守，第七境迎战归墟司命。绛鳞是前期守关者。人物志可以查看画卷与背景，镜中人、卫烬、心影、逆仪绛鳞本轮已换为完整高分辨率原画。

当前共有76张技能、134种剧情事件、126段事件音效和341张运行 WebP。核心剑意、魂息常驻名称、数字和刻度；敌方状态只在实际施加后显示符纹与右下角层数。卡牌目标选择仍有规则层预览，不公开敌方下一招。

## 下载与启动

- [完整游戏 ZIP](https://raw.githubusercontent.com/YONGLINGZ/CC/main/recovery/baiyao-rebuilt.zip)：全部解压，打开 `index.html`，保留 `assets/`。
- [完整单文件 HTML](https://raw.githubusercontent.com/YONGLINGZ/CC/main/baiyao-standalone.html)：保存为 `.html`，用桌面浏览器打开。

完全离线，无需安装、账号或大模型 API。攻击牌先点牌再点敌人，同牌再点一次或按 Esc 取消；无目标牌直接使用。顶部可查看牌组、包裹、手记、随身装备和人物志。开局带两份回春草，战斗中每个玩家回合可用一件药物。

夜铃和沈霜白开局衣囊持有墨羽行衣，默认仍穿原装；在「随身装备」中选择穿上即可更改立绘和效果。其余四套可在千灯灵坊购买，购买不会自动装备。战斗、战利结算及未处理事件中不能换装，衣装效果不叠加，重新开始清空购买并恢复原装。

本局不存档，角色解锁单独保存在浏览器，也可复制凭证迁移。浏览器支持时会对正在进行的一局显示离页确认；移动端仍可能直接关闭或回收页面。

原装保留三档生命立绘。五套衣装本轮没有另外绘制50%／25%两档战损图，仍有伤势标签与二维表现，低血量不会换回原装。人物采用静态原画配 CSS 动作和技能特效，尚无正式 Live2D 模型。自动回归策略仍可读取规则层内部意图，其胜率不能替代隐藏预告后的人工难度评价。
