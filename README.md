# 百妖夜契 · 寒渊因缘版

玄烬教的实验反噬，将寒渊封在无法窥视的黑雾中。选择猫妖刺客夜铃或冰霜剑修沈霜白，带着各自的牌组深入封域；门派弟子、寻宝客与魔教叛徒，也在这条路上寻找自己的出口。

本版行旅分成 **雾锁山门 → 断桥诸营 → 逆仪腹地**。每境四段，共十二段；走完一境才进入下一境，地图和立体地形只展示当前区域。已经走过的路不能返回。

**27 种剧情事件**包含三条跨区域的小故事。柳照青会记住救人的援手；季临川可能还你人情，也可能盯上曾经见过的宝物；救下闻人烛，则可能一同背上尚未解除的追踪。重要人物在三个区域各有一次相逢，后续由先前选择决定。行旅手记保存已发生的事，伏击会进入真实卡牌战斗。

## 下载与启动

- [下载完整游戏 ZIP](https://raw.githubusercontent.com/YONGLINGZ/CC/main/recovery/baiyao-rebuilt.zip)：全部解压，双击 `index.html`，保留旁边的 `assets/`。
- [下载完整单文件 HTML](https://raw.githubusercontent.com/YONGLINGZ/CC/main/baiyao-standalone.html)：保存为 `.html` 后用桌面浏览器打开。

游戏完全离线，不需要安装、服务器、账号或大模型 API。刷新会清空本局进度。聊天中的工作区路径不等于附件下载入口，上面的链接来自仓库文件。

## 操作

选择职业、开始闯楼、进入当前区域，再点亮起的路线地标。攻击牌先点牌再点敌人；同牌再点一次或按 Esc 取消。无目标牌点击即用。每回合基础 3 灵力，点“结束回合”让敌人执行已展示的行动。顶部可看牌组、遗物、行旅手记和声画设置。

保留 52 种职业技能、独立卡面和合成音效、三档战损立绘、精英秘宝和一次性契约。三维场景与人物是离线 WebGL 低多边形原型，仍可关闭。详细规则见 [GAME_README.md](GAME_README.md)，实际检查与限制见 [TESTING.md](TESTING.md)。
