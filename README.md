# 百妖夜契 · 寒渊七境

玄烬教的引灵实验反噬，寒渊被黑雾封闭。选择影契刺客夜铃、霜华剑修沈霜白，或在旅途中解锁第三位角色，沿七境深入。事件只交代当场见闻与对话，人物的打算留待途中判断。

每境十段，从地图底部向上抵达顶部 Boss；全程七十段。每境独立从 20 套线路模板抽取布局，包含 42—46 处互斥分支地标，全局共 294—322 处。小型五边形图标与连线表示真实通路，每段只能走一个相连节点，下一境抵达后开放。

镇境阵容共有九位：前期五位中抽取三位且不重复，第四至第六境分别面对三位中期镇守，第七境迎战归墟司命。绛鳞是前期守关者。首页“镇境人物志”可以展开各自的画卷、旧事与固定招式，设计记录见 [镇境者手札](docs/BOSSES.md)。

七境保留三职业 70 张技能、包裹、洞府、装备、地域影响及连续人物故事，并在后四境加入十二条独立奇遇，共 52 种剧情事件。战斗与旅途中的已知状态以小图标呈现，点击查看说明；卡牌与意图显示当前实际数值。

## 下载与启动

- [完整游戏 ZIP](https://raw.githubusercontent.com/YONGLINGZ/CC/main/recovery/baiyao-rebuilt.zip)：全部解压，打开 `index.html`，保留 `assets/`。
- [完整单文件 HTML](https://raw.githubusercontent.com/YONGLINGZ/CC/main/baiyao-standalone.html)：保存为 `.html`，用桌面浏览器打开。

完全离线，无需安装、账号或大模型 API。攻击牌先点牌再点敌人，同牌再点一次或按 Esc 取消；无目标牌直接使用。顶部可查看牌组、包裹、手记、装备和人物志。开局带两份回春草，战斗中每个玩家回合可用一件药物。

本局不存档，角色解锁单独保存在浏览器，也可复制凭证迁移。对正在进行的一局，浏览器支持时会显示离页确认；这不是存档，移动端仍可能直接关闭或回收页面。

运行资源共 258 张 WebP。本轮制作十二张独立人物图（九位 Boss、三位精英）和十六张场景图（四境背景、十二奇遇），其中三位旧 Boss 的图已替换。主角保留三档生命表现，攻击、受击和技能由 CSS 与二维特效呈现。玩法见 [GAME_README.md](GAME_README.md)，实际验证范围见 [TESTING.md](TESTING.md)，恢复说明见 [PERSISTENCE.md](PERSISTENCE.md)。

立绘与场景预览：[九位镇境者](docs/previews/bosses-v11.webp) · [脸型与神态](docs/previews/boss-faces-v11.webp) · [新地域与奇遇](docs/previews/scenes-v11.webp)。数值方案的核实和未达目标见 [审计记录](docs/BALANCE_AUDIT.md)。
