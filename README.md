# 百妖夜契 · 蚀心长夜版

玄烬教实验反噬，寒渊被黑雾封闭。选择影契刺客夜铃、霜华剑修沈霜白，或在满足条件后解锁第三位角色，沿三境深入。事件呈现当场见闻与对话，人物的打算留待途中判断。

本版每境十段，第十段迎战镇境 Boss；三境共三十段。每境独立从 20 套线路模板抽取布局，包含 42—46 处互斥分支地标，全程合计 126—138 处。每段只走一个相连地标。地图采用绘制背景、纵向交错连线和可点二维节点，会在容器内定位当前段；后方地域抵达后开放。

沈霜白的援手可能留下跨节点、跨战斗的缠脉毒。普通治疗只能续命，休息与抑毒散只能暂压毒性，根治需要后续剧情中的取舍。魔修技能可以恢复生命、护身，却会积累魔念：无清心玉护持时第六次使用便本局不可逆入魔，原剑修牌的伤害与护盾基础值减半，魔修牌保持威力。沈霜白仍是原来的角色，立绘与事件画面会随入魔改变；后续也能主动袭击原本愿意让路的人，真正战胜后夺取魔经。

三职业共 70 张技能、40 种剧情事件，另有狐妖、商店与休息。装备、灵识成长、地域影响、可选隐藏挑战及解锁角色的专属道路保留。进行中的一局不保存，角色解锁单独存于浏览器，也可复制凭证迁移。

## 下载与启动

- [完整游戏 ZIP](https://raw.githubusercontent.com/YONGLINGZ/CC/main/recovery/baiyao-rebuilt.zip)：全部解压，打开 `index.html`，保留 `assets/`。
- [完整单文件 HTML](https://raw.githubusercontent.com/YONGLINGZ/CC/main/baiyao-standalone.html)：保存为 `.html`，用桌面浏览器打开。

完全离线，无需安装、账号或大模型 API。攻击牌先点牌再点敌人，同牌再点一次或按 Esc 取消；无目标牌直接使用。顶部可查看牌组、手记、装备和解锁凭证。

运行资源共 233 张 WebP，含入魔后的三档人物图与 21 张事件变体。人物表现采用静态原画、生命三态和 CSS 特效，没有正式 Live2D Cubism 模型或三维场景。玩法见 [GAME_README.md](GAME_README.md)，验证记录见 [TESTING.md](TESTING.md)，恢复说明见 [PERSISTENCE.md](PERSISTENCE.md)。

实机截图：[剑修战斗](docs/previews/battle-v8.webp) · [入魔战破](docs/previews/fallen-v8.webp) · [入魔事件](docs/previews/event-fallen-v8.webp)。截图中的少数数值由验收 fixture 安排，用于展示状态，不代表自然开局。
