# 来时之路：角色出场分镜全文

每位角色4页专属故事＋2页世界介绍。既有原画重新编排为双画格，旁白与对白为本轮撰写/改编，不是新增手绘漫画。第5页共享世界说明，第6页对白按角色适配。
