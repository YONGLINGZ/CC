# 层境渐深 · 续灯长约

版本：2026.11.02-review.2。基线：d36665842f7caf523da0067f49e54b20067672fb。本轮开始时 fetch 的远端 main 与基线一致；独立本地分支 improve/difficulty-lifequest-v2，未推送、未部署。

## 结论

上一版的主要问题不是单纯“敌人血少”：一些怪在30段后停止成长，部分剧情战始终固定低血；不同镇境者之间存在很大的生命预算落差；九命铃可从单次事件或随机奖励得到，却每场重新免死，使后来很多危险失去意义。

这版补齐后段压力，抹平镇境生命预算的明显断层，并把两种玩家免死遗物统一改为需要实际交锋的任务奖励。保留五角色技能与不同打法，没有新增大量卡牌或事件。

难度应该总体随深入上升，而不是要求每一个节点都比前一个更难。休息、完成构筑、提前准备克制手段，仍应让玩家有变强的回报。本版也不宣称难度已经完美平衡。

## 难度与资源改动

1. 七境镇境者生命预算为95、120、145、175、205、235、270。保留各自招式、状态和行动权重；旧版第三境绛鳞可能245血而第四境镇守155血的倒挂被消除。早期某些Boss变轻，原本不成长的Boss则补齐成长，不是全面加血。
2. 旧怪前30段保持原基础成长，30段之后每段再增加基础生命的1.2%；例如纸偶第70段64→76血。已有七境预算的阵营怪不重复套生命倍数。原来固定生命的剧情交锋按深度补齐成长。
3. 第30段以后每深入15段，敌人整招的第一段伤害增加1，末段最多增加2。不会按每段重复加压，不放大三连击为三倍增量；观息与实际结算使用同一套数值。
4. 回春露胜利时最多回复8，且不超过本战入场后的净失血。不能再拿无伤简单战恢复之前几场累积的全部损耗。休息、药品、镇境补给保留。
5. 修为原本很早达到6级，本轮没有再把上限调高；玩家后期继续靠卡组、遗物、准备和路线选择成长，避免重新放大滚雪球。

第一轮尝试过更高的Boss血量和攻击增幅，150局旧策略仅21胜。该方案已撤回。最终数值使用较温和的曲线，不能把第一轮试验当作成品。

## 复活必须完成“续灯长约”

本项目实际给玩家免死的是狐契和九命铃，并非可复制的技能牌。“借命”C31只是自损换盾；敌人m26的借壳/代死属于敌人机制，本轮保留。普通护盾、治疗和阵营减伤不视为复活。

任务流程如下，每次办理都占用当前休息或狐灯节点，不能同时领取治疗：

1. **立约**：第49段以前，在任一休息/狐灯处付20灵石。
2. **护灯试炼**：立约后实际赢两场战斗，其中至少一场精英或镇境战。
3. **炼契**：进入比立约更后的一境，在休息/狐灯付6最大生命。
4. **镇境证明**：炼契后亲手击败一位镇境Boss。此前的击杀、和平通关、普通或精英战不能代替。
5. **二选一领取**：进入比炼契更后的一境，在休息/狐灯选择：再付20灵石领取狐契，免死后恢复至12生命；或再付4最大生命领取九命铃，免死后恢复至18生命。恢复均不超过生命上限。

两件奖励共享本局唯一领取记录，**全局只能触发一次**，触发后遗物消失。进入下一场战斗不会刷新，继续受到多段攻击仍可能死亡。最快可以在第三境领取，不必依赖随机掉落任务道具。

可以暂别、治疗或绕路后再继续；也可以主动放弃，但已付代价不返还、本局不能重启。死亡使未完成约定失败；重新开局清空任务。节点、手记和地图休息提示可查看进度、条件和代价。

## 获得与绕过检查

- 精英珍藏、洞府遗宝、通用秘宝池不再包含免死遗物。
- 戏台和借伞原来的单步九命铃奖励替换为普通秘宝，相关文字同步调整。
- 通用遗物发奖入口拒绝狐契/九命铃，即使旧待领取奖励中残留它们也不能取得。
- 复活结算要求完成任务、领取和未消耗的记录同时有效；只有旧遗物ID、重复塞入消耗过的遗物，均不生效。
- 本游戏没有合法单局存档；角色解锁导入只接收解锁信息，不导入复活遗物或任务记录。复制卡牌不能复制被动遗物。
- 离线游戏不提供对任意控制台篡改所有内部状态的防作弊保证；这里修的是正常入口、旧奖励与不完整状态绕过。

顺手修正洞府随机池可能掉落机关师初始线轴的问题；职业初始物不再混入公共洞府奖励。领取成功提示缩短，避免长段浮窗挡住手机手记。

## 剩余风险与下一步

剑修旧策略仅24%胜率，夜铃74%，职业差异仍显著；合欢和机关师尚没有本轮等量自然整局策略样本。旧数值门禁仍有未通过项，不能写成“全面平衡通过”。任务对休息机会和生命上限有真实成本，玩家是否愿意完成，需要自然游玩反馈。隐藏路线也需要单独观察。

这轮没有声称重新人工玩十局。建议下一轮优先记录真人剑修的死亡段数、是否完成续灯任务、后期普通战是否仍缺少决策；先据此微调，不继续堆内容。没有新增存档，没有改角色解锁条件。
