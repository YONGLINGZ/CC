# 陆听澜与V5剧情改造

发行标识：2026.10.26-j48-v5.1。

陆听澜是27岁的天工院外勤机关师。52初始生命，同心线轴在每场免费展开预设首发；三具唯一机体为承山、鸣镝、拾萤，同时在场两具。机匣提供展开、收回、换机、维修、充能、指令与过载，不必抽到召唤牌才能操作。

灵力用于出牌与调度；驱动上限6、开战2，从第二回合起自然增加1。最后主动执行者承受直接攻击，自动运转不改变护卫。机体损坏反馈3生命；多段伤害逐段处理溢出。收回不恢复耐久；损坏后维修，须等下一玩家回合才能重新展开。过载先付驱动和4耐久，再爆发退场。所有战斗机体状态下场重置。

J01—J48是48种独立牌，基础按钮不计入其中；J01/J02不进入普通奖励。每张卡显示执行者、友方目标和驱动费用，确认前可取消。角色专属事件在第4、18、46段插入，处理后回到原节点：桥口的旧机、封条里的销钉、出货账与活人（标题以实际数据为准）。证物只能由实际选择取得，角色身份不能跳过故宅机仆的双证物唤醒条件。

V5使用三个独立呈现模块：story-v5.js（通用事件、十套人间故事、合欢线和结局）、story-factions-v5.js（28洞府事件及交涉/善后）、story-bosses-v5.js（14条Boss旧事共42段）。数值、条件和发奖仍归引擎。Boss旧事精简为介入/离开两项；第三段为准备/离开。删除通用打工/包扎填充项，保留取证与准备的真实成本。

正文不再播报缺少物证的任务清单；已知代价与触发条件放在选项小字和风险摘要。结果展示新的动作、对白或物件变化。不同主角在部分共享场景有各自反应，结局读取本局事实，不自动宣告未完成的营救、寻人或解契已经完成。

完整事件审阅包仍为 recovery/events-md-export.zip，每个事件一个Markdown，同链同目录，含显式历史状态快照。快照与自动回归不能替代真人理解度和好玩程度测试；真实手机、5—8位玩家体验及角色长期平衡仍待人工验证。
