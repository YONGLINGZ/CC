| 流程 | 实际操作与断言 |
| --- | --- |
| 全新资料 | 隔离浏览器存储启动，检查 v2 默认值、可用入口、无凭空奖励 |
| v1 迁移 | 注入真实旧版解锁结构，刷新迁移后验证角色保留、v2 字段有效、重复刷新不重复奖励 |
| 开局设置 | 真实点击 mode、seed、contracts、challenges，核对引擎实际配置与同种子可复现性 |
| 续局 | 普通开局并真实 UI 完成第一场；记录稳定检查点，刷新继续，比较生命、卡组、地图、历史、回响次数及随机进度 |
| 藏珍库 | 明示已获得物品夹具；检查仅选一件回响、前三战消费、第四战不生效、刷新不重复消费 |
| 温养 | 在另一局通过首境后，旧冷却解除；本局携带的回响继续温养。明确首境夹具，完成真实 UI 战斗收尾，核对刷新后仍持久化 |
| 备份 | UI 导出包含资料与当前局的 v2 备份；正常字段往返一致；含有效资料但损坏旅程的备份整体拒绝，不先覆盖原资料 |
| 放弃限制 | 真实放弃后重开，检查不能刷新回响可用性、不能重复领结算、无保留的旧局续玩入口 |
| 结算分享 | 明示终局夹具；真实结算控件产生与该局一致的摘要，并测试复制/导出入口及失败后可手动复制 |
| 装备视觉 | 明示合法装备夹具；full/reduced/off 下检查装备形象与特效可见性，同时核对规则状态无差别 |
| 尺寸 | 320、390、1440 像素宽下检查设置、藏珍库、战斗与结算，验证横向无溢出、按钮可到达、敌方未裁切，留截图 |

当前未测：真实手机、真人理解度、完整七境自然通关、操作系统强制终止时的存储原子性。浏览器通过本机 HTTP 加载，不能冒称 `file://` 实测。
