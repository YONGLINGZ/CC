# 众生来意 · 全量阵营手册

37种关联模板、十四组阵营遭遇已经接入同一七境流程，覆盖九位镇境者与五个既有特殊遭遇。P1六种、P2十二种、P3九种、P4十种均有实际规则和图像；P5工程验证及尚未执行的设备／人工评价以TESTING.md为准。本页数值与菜单从当前规则数据生成，不冒充试玩结果。

## 共同判定

1. 节点已结算不能再次领取；进入洞口前有警示和绕行选项。
2. 已处理的Boss对应事件转善后，不补发过期委托。
3. 本NPC亲见的袭击，或有效且可识别的支持凭证，会进入正常玩家先手战斗；支持与反对同时持有仍按支持判敌对。
4. 普通旧证物只是调查资料，不算效忠。无效凭证不参与识别；支持护持用尽不等于凭证作废。
5. 合法反对凭证可交换一次援助。命枢还需真实放弃赤签的那次8护盾；醒梦人还需本局亲手落印的行为，不能只凭来历不明的符。
6. 无立场可付12灵石听证词，也可交回春草1换凝露叶1、主动战斗或离开。每次只结一个主结果；战斗只发标准战利与本节点证据，不兼领和平赠物。
7. 旧信物的完整抵消优先，新援助只减少一次实际状态；已全抵消时不浪费援助。支持方提供对应交锋首回合8护盾一次。
8. 资源按提交时重新核验；事件中服药后，缺草药或可支付的选项会同步变灰／恢复，不重抽菜单。亲见来历、已见招式和实际选过的证词记录在手记，渲染不写奖励或消耗随机数。

## 投放与先后

通常每境第4段尝试立场来源，固定剧情占满时第5段重试；第8段是一处可错过的阵营洞府。只使用当前可达且没有固定剧情／遭遇的节点，保持原连线。普通怪随实际关口进入候选；精英交涉者不混入普通池，同一新模板不连续抽中。

绯夜主角前三境仍面对镜中人、卫烬、逆仪绛鳞，第26段还有心影。心影组来源在21／22段的合法支路、洞府在25段；普通关联影只在此前窗口介入。其他主角不借用这四组个人遭遇。

末境每局只选择司命或旧名契之一作为主要阵营洞府主题；两位来客与绯夜本人都可能面对旧名契制度，但绯夜不会生成敌对本尊。旧名契主题在66段给来源、67段给祠堂；来客听过旧事后、宫主收回本源后，宫侍才进入普通候选。宫主的对话改为维持旧制或还名；归宫名契护盾与无字路签减封灵用于命枢交锋，普通来客仍对应井下交锋。旁支不改原隐藏条件，得到名帖或无字路签均不解锁角色；正当通行也不算跳过隐藏门槛。

固定个人线、十四套旧事链优先。来源可以错过，未做的选择只会留下空白，不会卡死共同主线。帮助、取援助与击退后有不同回声；未送到的信不写成已送达，没有放弃护持不写成已放弃，一道白缝不写成整口井已净。

## 数值与当前状态

七境A／D／H分别为7／6／32、8／7／40、9／8／48、10／9／60、11／10／70、12／11／80、13／12／88；这些已是目标预算，不再叠旧段数倍率。精英取1.5H向下取整；新模板不因种族或精英身份自动免疫猎印、霜寒、流血和吸血。两招带权随机首招，其后排除上一招；Boss保留固定轮转且界面不预告下一招。

- 代死账：借壳治疗与致命伤保留1生命共用一次。卡牌、毒、流血都能用掉它，真正失去多少生命才吸取多少，不提前判击杀治疗。
- 瓮裂：单张攻击牌累计削盾达到本境D，后续抱紧护盾永久减少3；连击按一张牌累计，两张牌不合并。
- 薄粉：覆粉后的下一张攻击牌首次生命伤害额外+2。完全挡住时保留，只放大一段，不叠加；属于敌方弱点，独立于玩家首段增幅上限8。预览与实际同用规则结算。
- 未决蓄势：完整玩家回合未受生命伤害，储存下一次攻击首段+2，最多一份；纯盾不消耗，攻击后清除。已生效时显示图标角标。
- 堤线：首次有追索印的攻击后额外护盾3，全战一次。局部清印／清血、治疗和封灵／减抽牌均按各模板限次执行。
