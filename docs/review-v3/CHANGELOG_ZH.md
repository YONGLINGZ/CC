## 已确认的问题与修复

上轮紧凑布局是这次画面退化的重要原因。桌面战场被限制为220px，机关师160px，窄屏150px；Boss完整纵向图片缩在矮容器里，名字与血条又绝对定位覆盖图片。合欢与机关师保留165%和145%的旧版裁切放大，进一步造成只露局部身体的怪异效果。已删除这些冲突规则，不再沿用固定矮战场。

新版桌面画像区320px，窄屏230px；名字、血条和状态另占下方正常文档流。所有战斗立绘使用等比 contain，取消合欢和机关师的特殊放大。原画未重新生成、没有拉伸脸部，没有透明图片后面的SVG重影。渡灯人从220px容器内、约147px宽且有遮挡的图片，恢复为320px高、约213px宽且无遮挡的画面。布局检查覆盖五角色、九位Boss、1440/360/390/430四种宽度，共180组。

事件选项首项原为浅金底，但说明和风险文字继承了固定浅色；禁用按钮还整体降到0.4透明度。现在浅底配深字、深底配浅字，正文/说明/代价/风险共用同一表面配色，禁用以虚线和灰底区别而不降低文字透明度。字号正文15px、说明13px。164事件在桌面和390宽度各检查一次，328个画面均无横向溢出，实测最低文字对比度7.22:1；另测三种按钮类型的正常、悬停、禁用、焦点，共12组。

## 角色动作的实际完成范围

夜铃、沈霜白、晏绮罗、陆听澜、绯夜均具备轻缓待机与职业差异的攻击节奏。攻击、受击、防御仍由真实战斗结算驱动；机关师按实际执行者和接招者播放。本轮增加单角色单动作轨道，新的连续命中会取消上一段位移，不把多段动画叠加成形变；动作不再放大原画。保留现有技能、机傀和数字特效。减少动态模式停止画像位移和待机，也隐藏相应残影与受击闪光。

这不是正式 Live2D。仓库没有 .moc3/.model3.json、分层PSD或Cubism运行时；已有旧puppet脚本也不是Cubism，不能把一份旧猫耳权重套给五个人物。此次采用完整原画的二维动画，未制作眼口开合、独立发丝/衣袖骨骼或转头模型。真正达到用户要求仍需五角色分层原画、遮挡补画、逐角度模型参数/物理绑定、攻击和受击动作文件，以及授权适当的运行时接入与模型验收。不能把当前替代方案称为“完成五个Live2D”。
