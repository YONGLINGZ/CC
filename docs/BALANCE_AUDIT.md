# 数值方案核实记录 · 寒渊七境 v11

此记录核对用户提供的游有方定稿与当前洞府寻珍版代码。被注明作废的另一份草稿不作为数值依据。用户同时要求扩为七境，因此三十段方案中依赖旧内容总量、最终 Boss 或测试基线的部分按当前结构修正。

## 已核实的适用项

| 项目 | 本轮实现口径 |
| --- | --- |
| 敌人生命成长 | 只对指定白名单生效，倍率 `1＋hpSlope×(clamp(f,1,30)−1)`，生命四舍五入；第三十段后封顶。 |
| 攻击成长 | 每段攻击按 `floor((clamp(f,1,30)−1)/4)` 加数，普通上限4、精英6、Boss0；先加数，再处理霜寒。 |
| 开关 | `createGame({scaling:false})` 可关闭成长；默认开启。旧三境隔离检查可明确使用 legacy campaign，七境是产品默认。 |
| 首段额外增伤 | 所有来源汇总后统一封顶8，再写入日志与结算；后续连段不重复加成。 |
| C35 盾返 | 1费，`4＋min(10，护盾)`，稀有。 |
| D04 魔躯 | 1费，获得10护盾，不抽牌；数据、实际结算与模拟镜像同步。 |
| 意图 | 普通／精英带权选招，开场也选择；排除上一招。Boss无权重，保留固定开场和固定轮转。查看意图不重新抽选。 |
| 精英 | 加入雾中伥、断桥灯魁和逆仪祭司；引入可见追索印及恢复招式，实际意图须显示完整数值。 |
| 构建 | `node dev/build.cjs --all` 一次严格检查声明素材并生成目录版和单文件，避免遗漏重建。 |
| 统计与旧报告 | 境末Boss包含最终关，七境正常通关计7；删除旧90局格式的过时报表。 |

最终保留 `hpSlope=0.05` 与首段额外增伤cap8。数值配置、固定种子及完整结果均记录在最终报告，不按失败目标反向挑选种子或更换策略。

追索印不是玩家施给敌人的猎印：它附在玩家身上，最多5层；下一次敌方行动首段攻击增加对应伤害后消耗。新施加的追索印在该次攻击之后加入，留到后续行动生效。此行为必须在状态详情和意图里说明。

## 验收口径

规则、界面及恢复检查通过，不能替代平衡目标达标。150局模拟采用固定种子与预先固定策略，三职业各50局，失败尝试同样保留；不能筛选种子、修改生命、放弃记录失败或反向调整策略来制造40—60%的胜率。

通关残血应同时报告实际生命和按60最大生命归一化后的数值，以区别狐契减上限、神血加上限等既有成长。最大单击应报告中位数以及高基础终结牌的分布，不能把额外增伤上限解释为所有牌的总伤害上限。

七境的流程长度与补给次数已经改变，三十段方案的40—60%胜率、15—25/60残血、职业25—75%胜率、精英5—9回合／Boss8—14回合及认真防守净掉血小于20等目标，仍须由当前七十段实测分别核对。未达标项应明示，并按用户允许的旋钮逐轮校准；不得仅因规则测试全绿而声称平衡验收全部通过。

本轮冻结成品的规则252/252、Chromium17/17组、258张图片解码、导出及恢复均实际通过；数值门禁结果单独列于下节与 `TESTING.md`，不能以程序检查通过替代平衡达标。

## 冻结七境实测与测量修正

最终 `v11-playtest-report.json`、`v11-elite-probe-report.json` 保留全部固定种子结果；`v11-balance-audit.json` 比较了初始基线与测量修正版，150局所有非测量字段完全一致。原始基线保留用于追溯测量错误，不能作为未经修正的验收证据。

| 目标 | 冻结版本实际值 | 判定 |
| --- | --- | --- |
| 150局总胜率40—60% | 90胜／150局，60% | 达标 |
| 三职业各25—75% | 夜铃72%、沈霜白34%、绯夜74% | 达标 |
| 通关残血中位15—25 | 实际生命39；按60归一化39.53 | 未达标 |
| maxHit中位≤34 | 49 | 未达标；额外增伤cap8已独立通过，既有高基础终结牌不能据此删去 |
| 精英5—9回合 | 中位7回合 | 达标 |
| Boss8—14回合 | 中位5回合 | 未达标 |
| 认真防守净掉血＜20 | 战斗内净失血中位13 | 达到该自动防守探针指标；不等于人工防守评价 |

冻结版本七项门禁为四项达到、三项未达到。60%并不大于60%，因此没有触发“胜率>60%时将斜率改为0.06”的校准条件。保持0.05和cap8，不能为了让报表全绿而擅自加码、削掉基础终结式或挑选更有利的种子。

**原探针净失血中位0已作废，不能作为通过证据。** 错误原因是战斗结束后的休息、事件等继续覆盖结束时生命。修正后的探针只取首次结束快照，战斗内净失血排除胜利标记后的回复；334次获胜精英／Boss遭遇的中位为13。`v11-balance-audit.json` 证实150局所有非测量结果与基线相同，本轮未通过改玩法来改变报表。

原始maxHit中位数仍为49。审计确认50局绯夜的最大单击均来自F12；剑修49局来自S16、1局来自S04，都是既有资源终结式；“基础公式较高”解释了适用差异，不会把原始≤34门禁改写为通过。仍需重新定义合理门禁与人工平衡试玩，不能宣称全部数值验收已经完成。
