# 器物与来意 · 首批完整样段

本轮实现M01失味膳役、M02缝门纸偶、M03夺谱探客、M19添愿炉役、M20寿契灰客、M21断契拾灰人。其余31种候选保留于用户规划，未伪称已完成。

## 玩法与边界

六种模板定义、逐境整数预算、两组事件及凭证均在dev/enemy-factions.js。关联普通怪只随本局实际Boss进入候选；事件精英不混进普通池；新怪不再叠旧倍率、不因非人身份免疫标记/霜寒/流血/吸血。两个技能按权重选首招并避开上次，故惩罚、纯盾、恢复不会连续刷。

膳役半血后每段+1，完成该次敌方行动后自损2，最多三次；不会在玩家牌中途加行动。炉役蓄热上限1，下一次攻击首段+3后消耗。灰客只按实际扣去生命治疗，每次最多3、全战最多6，护盾与过量不计。探客拆护先额外削盾3，不溢出生命。纸偶反击沿用每牌首次伤生命一次。

支持凭证自动识别优先于反对凭证；已无效者不识别；普通证物藏包不算立场。进入前有警示，敌对后正常玩家先手，非免费偷袭。NPC行为事实只记录提交后的本次见闻，不建立全局善恶分。Boss已击败/唤醒则事件为善后，不再发过期委托。

每事件记录绑定节点ID；战斗证据回调同时核对实例及敌人ID。和平完成、主动攻击、凭证敌对、离开各只结一次，不同时发赠物和标准战利。新工具不替代原两件机仆信物或调查记录；不做毁芯分支，因此不会暗中封掉原唤醒路线。

## 美术

20张独立运行图：六待机、六同身份战斗姿态、四凭证、两援助物、两独立场景。人和景分开；头像本轮复用完整立绘的浏览器构图，不虚计新作。PNG母图保留于recovery/factions-art-originals.zip；运行WebP、哈希及透明通道信息在dev/faction-art-manifest.json。使用二维位移和各怪器物符形特效、分材质合成声音，无新Live2D模型。

封灵药与残阵互相作用是本轮新增现场痕迹，尚未指认投毒者；不改写旧木匠、修器女修的证词、纵火案与完整遗言。

## 技能与投放核对表

A／D／H依次按境取值：第一境7／6／32，之后为8／7／40、9／8／48、10／9／60、11／10／70、12／11／80、13／12／88。精英生命为向下取整的1.5H；这些数值不再次叠旧成长。

| 模板 | 生命 | 两种行动 | 特性 |
| --- | --- | --- | --- |
| 失味膳役 | H | 抢食：两段合计A；掀笼：A−2伤害、护盾⌊D/2⌋ | 半血饥乱最多三次，详见上文 |
| 缝门纸偶 | H−2 | 缀门：护盾D、反击1；逐客：A伤害 | 有有效家令可和平通过，仍可主动交锋 |
| 夺谱探客 | ⌊1.5H⌋ | 钩匣：A伤害、下回合少抽1；拆护：先额外削盾3，再造成A+2伤害 | 只在对应洞府交锋 |
| 添愿炉役 | H | 投愿：A伤害；拨炉：护盾D、蓄热1 | 蓄热仅下一次攻击首段+3 |
| 寿契灰客 | H | 借年：A−2伤害并有限吸取；烬掌：两段合计A | 每次最多治疗3、全战最多6 |
| 断契拾灰人 | ⌊1.5H⌋ | 灰刃：A+1伤害；封炉灰：A−2伤害、下回合灵力−1 | 只在对应洞府交锋 |

两段攻击先⌊A/2⌋、再补余数，逐段结算；所有六种都可以正常承受猎印、霜寒、流血，不设种族免疫。技能名称只在行动发生后进入手记，不预先列出下一招。

| 洞府前状态 | 进入后的处理 | 主结果 |
| --- | --- | --- |
| 有效支持凭证（包括同时有反对凭证） | 认出公开凭证，立即进入正常玩家先手精英战 | 胜利仅标准精英战利＋本次残页证据 |
| 仅有效反对凭证 | 四选项交涉 | 援助／换药／主动战斗／离开，四者互斥 |
| 无凭证或只有旧调查证物 | 四选项交涉 | 12灵石换实际证词／换药／主动战斗／离开 |
| 凭证无效 | 不作为立场识别 | 按其余有效凭证处理 |
| Boss已唤醒或击败 | 善后文本 | 不补发过期委托或援助 |
| 节点已结算 | 不可再次选择或回访 | 不重复消耗、发奖或战斗 |

回调按节点实例与敌人ID双核对；失败不发胜利证据。接受取谱承诺后，纸偶会询问工具声响；满足原条件唤醒缄红时，可坦白委托转而救人或退还工具。事件不会自行宣告毁芯、杀死对方、解契或救出全部伤者。
