# 灯渡与旧誓 · P2

本批新增M04—M15，补齐计划的五个前期Boss关联组。焚愿组三种继续保留，现共18种；P3余九种与P4十种尚未实现，不以命名或规划算作完成。

## 连贯的四组冲突

- **不点灯的渡棚**：照微的灯照顾有名者，也拦住空名背夫。渡客承认剪断拦路链后，曾有人未跟上逃船；援助者不因反对Boss就获得清白。
- **堤下伤卒营**：闻铮守着剩余药物，逃卒却说必须带伤者走。他曾用另一队人作诱饵，不能将救伤写成没有牺牲的成功。
- **秤鳞石窟**：采鳞者明确逐利，药账同时记录买主要求加量和卖方多收的钱。交药只帮助眼前药工，旧方不自动治愈依赖。
- **无钟墓室**：掘名者曾认错一块碑；如今逐字问证，不再替所有人决定送别。补全墓名与系名留魂是两个独立行为。

每组入口有实际四选项：接受支持约定／实施另一方行动／只调查／离去。选择后取得不同凭证；调查物不算效忠。洞府先警示再探入：有效支持凭证优先引战，包括同时持两边凭证；反对凭证可换援助；无凭证可付12灵石听取完整证词；其余可交草换药、主动交锋或离开。资源在提交时再次检查，每节点只结算一个主结果。Boss已处理则转善后，不发过期任务。

接受护持在对应Boss战首回合获得8护盾一次，使用后仍能被辨认。援助分别抵消首次追索印1／封灵1／施毒1／减抽牌1，原有完整抵消先执行，效果已全抵消时不浪费新援助。Boss战后只回收本局真正完成的救助、援助或夺证，不虚构所有人获救。
