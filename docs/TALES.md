# 十段人间事 · 已接入的剧情链

这十套是可在同一局里留下前因后果的事件，不是首页新增职业，也不是替换主线结局。每局固定抽取三套，每套三次相逢。初逢、重遇和余波分别读取本局真正做过的选择；错过前段不会在后面凭空变成故人。三名主角使用各自牌池的功法奖励，共享场景图只画当事人与环境，不借用猫女作为剑修的代身。

上述不是游戏内的善恶说明。界面只呈现当场言行、可知代价与已见往事，人物不挂“坏人”“夺宝者”等预告标签。

## 真实的规则后果

各阶段的灵石、包裹、治疗、下一战护盾、主角功法或剑器奖励均由规则层处理，选择只领取一次。三次相逢不是三段固定旁白：后两段读取前段的具体选项，复述的“你记得”来自上一次实际结果。

杜蘅的署名见证或迁移病人、石砚的核查证言、许渡的临时伤籍、阿筠先征询家属等实际选择，可以让后续火塘围剿多出“出示见证”的交涉路径。没有做过或没有遇见，就没有这份证词。其它故事不会为了凑数统一加一个隐藏善恶分数。

## 旅途中的突发事件

- 完成12个节点后，下一处合适的普通战斗路径会先遇见翻倒的药车；之后至少再走14个节点，最多出现三次。首见与重遇读取此前是否真帮过车队。委托、援助、绕路都会真实完成当前节点，不重复刷钱，也不伪装成一次已经打赢的战斗。
- 剑修已经发生霜心异变时，下一处未被关键事件占用的休息点会遇到执炬巡使。两次围剿至少相隔8段，一局最多两次，不占用Boss或已有关键剧情。
- 应战面对48生命的巡使，按固定次序使用“攻击8并施加2追索印 → 护盾7并少抽1张 → 连击4×3”。胜利正常发放一次战利；领取或跳过卡牌后，返回原来的休息点，休息结束才完成这一个地图节点。
- 可以支付20灵石交涉；持有来自已执行援助的证词可免费交涉。这两条都保留原休息。无力或不愿交涉时可免费撤离，代价是放弃这次休息，没有额外直接扣血。

事件在踏入节点时决定一次，查看牌组、包裹、手记或重绘页面不会重抽。追兵与路遇有冷却，不会每个火塘都连续刷敌人。

## 调度与维护

数据在 `dev/tales.js`，调度、选择和突发事件接线在 `dev/engine.js`。三条本局支线通常安排在6／26／46、8／38／58、12／32／62段；绯夜首条重遇移到36段，保留26段心魔交锋。实际机会只放在当前真正连通的节点，不添加或删除路线连线，不覆盖已有故事或镇境战。阶段未完成则后续机会保持普通节点，故事留作未竟。

地图、奖励、主角与起手仍按既有七境规则进行。它们不是新的主线结局，也没有新增单局存档。验证范围以根目录 TESTING.md 为准。

三十段连续事件各有一张独立场景图，加上洞府、路遇、围剿与巡使立绘，共34张新画。原始PNG保留于生成目录，运行只用本地WebP；图缺失时仍可完成规则流程。
