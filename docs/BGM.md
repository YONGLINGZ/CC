# 寒渊小曲 · 灯下行

原创古风游戏配乐，80秒循环，72 BPM，D宫五声。仿古琴拨弦构成疏朗伴奏，轻箫在句间留出呼吸，偶尔用泛音回应。无鼓点、无强烈高潮；探索、事件和战斗保持同一主题，避免来回切歌打断阅读和出牌。

首次点击页面控件后启用。声画设置中的「寒渊小曲」提供独立开关与音量；总音量和静音同时控制音乐与技能声。关闭配乐仍保留技能音效。切入后台暂停，返回后渐入并续接之前位置。刷新页面恢复默认设置，不保存本局进度。

游戏从固定乐谱离线合成PCM，缓存在单个立体声循环音源中，与技能音效共用一个AudioContext。循环尾音及早期反射按环形处理，音量平滑变化。无音频下载、fetch、在线服务或额外依赖。读取乐谱、切换音乐和调节音量不会使用游戏随机数或修改游戏状态。

`docs/audio/hanyuan-lantern.mp3` 是可单独试听的完整导出，首尾增加淡入淡出；游戏内使用带尾音衔接的循环版本。程序音色模拟古琴与箫，未使用真人演奏或商业音乐采样。听感仍需玩家试听反馈，不把波形检测当作人工听评。

开发重导出：`node dev/export-bgm.cjs`（只在开发时需要FFmpeg，游戏运行不需要）。检查：`node --test dev/music.test.cjs`、`node dev/music-browser.test.cjs`。前者检查音阶、确定性、波形、峰值和循环衔接；后者实际检查点击解锁、单音源、独立音量/开关、总静音、后台、移动布局与单文件离线播放。
